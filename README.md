### Inscit
**A focused study experience, designed for offline use.**

Inscit is an Android study app exploring how local-first design and focused study sessions can make learning workflows more practical.

- Offline-first direction
- Timed Rapid Sprint sessions
- Local data approach
- High-contrast dark interface

`Kotlin` &nbsp; `Android` &nbsp; `Productivity`
